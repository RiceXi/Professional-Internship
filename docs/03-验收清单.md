# 任务一验收清单

本项目选择[任务书](../面向大模型推理优化的操作系统级任务设计_合并版.docx)中的 KV Cache 分页内存管理任务。以下按任务一和通用考核要求整理，便于提交前核对。

## 实现与测试

| 内容 | 状态 | 对应文件 |
|---|---|---|
| 分页、页表、动态扩展与回收 | CPU 测试通过 | `src/memory/paging.py`、`test/cpu/test_memory.py` |
| 连续预分配基线与碎片统计 | 测试与仿真实验完成 | `src/memory/contiguous.py`、`bench/bench_memory.py` |
| fork、引用计数与 COW | CPU 测试通过 | `test/cpu/test_cow.py` |
| 有界主机页池、LRU、固定工作集 | CPU 测试通过 | `test/cpu/test_swap.py` |
| 仿真器覆盖率 ≥70% | 纯 CPU 环境约 82%，含 CPU 张量测试约 94% | `experiments/task1/tests-*` |
| KV 张量后端与引擎接入 | 已接入，CPU 张量测试通过 | `src/memory/torch_storage.py`、`src/memory/gpu_engine.py` |
| GPU 页往返与模型输出对照 | 待在 RTX 4060 Laptop 上运行 | `test/validate_gpu.py` |
| GPU 并发、长上下文、显存峰值和换页开销 | 待实测 | `scripts/gpu_matrix.py` |
| 对话或长文本负载 | 已接入 Azure LLM 真实轨迹（CPU 仿真），ShareGPT/LongBench 加载器可用 | `bench/bench_trace.py`、`experiments/task1/trace/` |

运行 GPU 验证后，保存环境清单和原始报告，再更新评测文档与 PPT。录屏使用同一版本的代码和结果，失败或未完成的实验在报告中说明。

开发历史可用 `git log --oneline` 查看。各阶段分别提交，便于查找实现和回退修改。
